  <action>
Create `tests/check-token-collision.cjs` as a CommonJS Node script (no transpile, no deps):

  - Reads `src/styles/global.css` and (if it exists) `src/styles/v2/global.css` from disk via `fs.readFileSync` with utf8 encoding.
  - Extracts all custom-property declaration NAMES (not values) from each file using the regex `/--([a-zA-Z][a-zA-Z0-9-]*)\s*:/g` capturing group 1. Strip duplicates within each file (Set).
  - Computes the intersection of the two name sets.
  - If `src/styles/v2/global.css` does NOT exist yet (this script may run before plan 23-02 task 2 completes), prints a clear "v2 stylesheet not yet present — skipping collision check (no-op pass)" message and exits 0. This makes the script safe to wire into pre-build hooks even before v2 lands.
  - If the intersection is non-empty: print each colliding name on its own line prefixed with "COLLISION: --", print the total count, and `process.exit(1)`.
  - If the intersection is empty: print "OK: no token name collisions between src/styles/global.css and src/styles/v2/global.css (checked N v1 names, M v2 names)" and `process.exit(0)`.
  - Handle the file-not-found case for `src/styles/global.css` (v1) by exiting 0 with a "v1 stylesheet not present — nothing to check" message (defensive: Phase 30 will eventually delete this file).
  - File extension MUST be `.cjs` (not `.js`) because `package.json` has `"type": "module"` and the script uses CommonJS `require`.

Add NO npm scripts in this task (task 3 of plan 23-02 wires it into the verification flow).

Self-check: after writing, run `node tests/check-token-collision.cjs` from the repo root. It should exit 0 with the "v2 stylesheet not yet present — skipping" message (because task 2 hasn't run yet) OR a real comparison if task 2 has already run.
  </action>
