Step 3 (verify open): Call `mcp__pencil__get_editor_state` again and confirm the active document path matches the Crito file.

Step 4 (inspect canonical nodes from CONTEXT D-18):
- `mcp__pencil__batch_get` with `nodeIds: ["wM9Ac"]` (nav text — body/nav font source). Read its `font.family`, `font.size`, `fill` fields.
- `mcp__pencil__batch_get` with `nodeIds: ["35XXR"]` at readDepth 2 (the "We help to grow" section — heading font + section bg color source). Find the headline text node child; read its `font.family`, `font.size`, `fill`. Read the section frame's `fill` for surface color.

- `mcp__pencil__batch_get` with `nodeIds: ["Y1ldm"]` at readDepth 3 (footer — confirms whether navy doubles as footer bg). Read footer frame `fill` and any text-fill children.
- `mcp__pencil__batch_get` with `nodeIds: ["ULZiU"]` at readDepth 2 (header — for border-bottom or shadow color → `--color-border`). Read any stroke/border properties.
- `mcp__pencil__batch_get` with `nodeIds: ["ujMLJ"]` at readDepth 1 (Home Page frame — for max-width / container width inference). Read `width` and child Y-coordinates of major sections (sample 2-3 section gaps for `--space-2xl` rhythm).

Capture the latest version. If `npm view` errors with `404`, the package does not exist — fall back to a documented Fontsource alternative or ask the user.

  - `## Spacing` — table with columns: Token | Source observation (Crito Y-delta or padding sample) | Recommended value (rem) | Confidence
  - `## Radii` — table with columns: Token | Source node | Crito cornerRadius | Recommended value | Confidence
  - `## v2 Token Mapping Table` — 2-column: Pencil variable name (e.g. `color/primary`) | CSS custom property (e.g. `--color-primary`). MUST include every token RESEARCH §2, §3, §4 enumerates: 8 colors, 6 spacing, 4 radii, 8 sizes, 2 font families, 3 weights, 2 leadings.
