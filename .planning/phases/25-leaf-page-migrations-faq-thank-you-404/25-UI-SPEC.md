## Spacing Scale

Locked by Phase 23 `src/styles/v2/global.css` `@theme` block (lines 26–31). t-shirt scale via Tailwind v4's `--spacing-*` namespace; every value is a multiple of 8px (multiples of 4 satisfied).

| Token | CSS variable | Value | Usage in Phase 25 |
|-------|--------------|-------|-------------------|
| xs | `--spacing-xs` | 8px (0.5rem) | Icon→label gap inside Button; `gap-xs` between secondary text-link and primary CTA on `/thank-you` |
| sm | `--spacing-sm` | 16px (1rem) | `<summary>` vertical padding (`py-sm`) on `/faq` accordion rows; `pt-sm` above answer wrapper; gap between secondary link and primary Button on `/thank-you` (`~mt-sm`); container side-padding fallback on narrow mobile |
| md | `--spacing-md` | 24px (1.5rem) | `pb-md` below answer text on `/faq`; CardBody internal padding (default) on `/thank-you` and `/404` cards; `gap-md` between the four destination Cards on `/404` |
| lg | `--spacing-lg` | 32px (2rem) | CardBody internal padding (elevated `/thank-you` card uses `px-lg`); page container side gutter; vertical rhythm between accordion section and CTA banner on `/faq` |
| xl | `--spacing-xl` | 48px (3rem) | Vertical breathing room above/below the page-header banner on `/faq`; `CardBody py-xl` on `/thank-you`; top margin above the `/404` destination grid (`~mt-xl`) |
| 2xl | `--spacing-2xl` | 80px (5rem) | Section breathing room — full-block vertical padding on the `/faq` top banner (matches `/blog` index banner per D-25-01) and bottom CTA banner (D-25-02); top margin above the `/404` 404 numeral (`~mt-2xl` per D-25-14) |

**Exceptions (intentional, documented to prevent checker false-positives):**
- **`/thank-you` outer wrapper** uses `min-h-[70vh]` for vertical centering — `70vh` is a viewport unit, not a spacing token. Preserved from v1 layout pattern (D-25-07).
- **`/404` numeral font-size** (`text-8xl` = 96px or larger) is a TYPOGRAPHY value, not a spacing value — listed under Typography below. Documented here only to clarify it is not a spacing exception.
- **Card max-widths**: `/thank-you` Card uses `max-w-2xl` (Tailwind built-in 42rem); `/404` destination grid container uses `max-w-4xl` (56rem). These are Tailwind layout constraints, not token-scale spacing.

**Forbidden in this phase:**
- No literal pixel/rem values for component padding, margin, or gap that bypass the `--spacing-*` scale.
- No new `--spacing-*` tokens introduced (Phase 23 set is locked; CONTEXT confirms "Plan 25-01 and 25-02 add zero new tokens").

**Counts (checker dimensions):**
- Distinct sizes consumed: **5** (`text-8xl`, `--text-display`, `--text-h2`, `--text-h3`, `--text-body`, `--text-small`). The 404 numeral counts as a single display step beyond the standard scale; treat as an exceptional one-off (single page, single glyph).
- Distinct weights consumed: **2** (`--font-weight-text` 400 + `--font-weight-text-bold` 500), plus `--font-weight-display` 700 reserved exclusively for headings + the 404 numeral. The 700-on-headings rule mirrors Phase 24.
- Body line-height: **1.6** (`--leading-text`)
- Heading line-height: **1.4** (`--leading-display`)

**Font assignment rule (locked, mirrors Phase 24):**
- Headings (h1, h2, h3), the `/404` numeral, and all Button labels → `--font-display` (Plus Jakarta Sans Variable)
- Body paragraphs, breadcrumb text, description sub-lines, secondary text link → `--font-text` (Inter Variable)
- No third font, no `--font-heading` / `--font-body` (collides with v1 — D-08).

**Style rules (locked):**
- **No `uppercase` text-transform anywhere** (Phase 26 D-26-04 carry-forward; explicitly flagged for `/thank-you` where v1 had `uppercase` on the h1 — DROP per D-25-09).
- **No `text-transform`, no `letter-spacing` adjustments** on body or headings — Crito uses none.
- **Single-color heading personality**: all h1/h2/h3 use `--color-primary` (navy). No accent-color text in headings. No underline-as-decoration on headings.

**Tone rules (locked, mirrors Phase 24 + Phase 26):**

H2s on `/faq` CTA and `/404` tagline DO end with a period — they read as full sentences ("Still have questions? Let's talk." / "This page wandered off.").
