## Spacing Scale

The v2 token system uses a t-shirt scale registered under Tailwind v4's `--spacing-*` namespace. Values below are pulled verbatim from `src/styles/v2/global.css` lines 38-43 — no new tokens are added in this phase.

| Token | Value | px | Usage in this phase |
|-------|-------|----|----|
| `--spacing-xs` (`p-xs`, `gap-xs`) | 0.5rem | 8px | Icon→label gap inside Button (already wired via primitive); FAQ ChevronDown→summary text spacing |
| `--spacing-sm` (`p-sm`, `gap-sm`) | 1rem | 16px | Vertical gap between FAQ rows (`gap-sm`); thank-you Button group inner gap |
| `--spacing-md` (`p-md`, `gap-md`) | 1.5rem | 24px | **FAQ row padding (locked — D-01 discretion resolved)**; CardBody default padding (already wired in `CardBody.astro` line 9 as `px-md py-md`); FAQ heading→lede gap; thank-you/404 vertical content stack gap (`gap-md`) |
| `--spacing-lg` (`p-lg`, `py-lg`) | 2rem | 32px | Container side padding (`px-lg`); FAQ list→bottom-CTA separation |
| `--spacing-xl` (`py-xl`, `mb-xl`) | 3rem | 48px | FAQ H1→FAQ list block-level breathing room |
| `--spacing-2xl` (`py-2xl`) | 5rem | 80px | Top/bottom section breathing room on `/faq` (matches `/design-system` page rhythm — `py-2xl` on outer container) |

**Exceptions:**
- `min-h-[70vh]` arbitrary value on the centered-Card outer container for `/thank-you` and `/404`. This is a viewport-relative minimum height (not a token-driven length), pulled verbatim from the current v1 `/thank-you` per D-14 and re-used for `/404` per D-12. It is the ONLY arbitrary length permitted in this phase. Do not introduce other arbitrary `[…]` values.
- Button internal padding is owned by the Button primitive (`Button.astro` lines 39-43, e.g. `size="md"` = `px-5 py-sm`). Pages MUST NOT override Button padding via `class` — pass `size` instead.

**Family utilities:**

## Component Composition (the per-page wireframe contract)

### `/faq` (overwrites `src/pages/faq.astro` in place)

```
BaseLayout (v2)
  <slot name="head">
    <script type="application/ld+json" set:html={JSON.stringify(faqSchema)} />   <!-- D-08 -->
  </slot>

  <section class="py-2xl px-lg">
    <div class="container mx-auto max-w-3xl">

      <!-- Heading + lede -->
      <h1 class="font-display text-h1 font-bold text-text mb-md text-center">
        Frequently Asked Questions
      </h1>
      <p class="font-text text-body text-text-muted mb-xl text-center">
        Common questions about working together. If yours isn't here, let's talk.
      </p>

      <!-- 5 FAQ rows (D-01: bordered rows, p-md padding, gap-sm between rows) -->
      <div class="flex flex-col gap-sm mb-xl">
        {faqs.map(faq => (
          <details class="group border border-border rounded-lg p-md bg-surface">
            <summary class="font-display text-h3 font-bold text-text cursor-pointer list-none flex items-center justify-between gap-md">
              <span>{faq.question}</span>
              <ChevronDown
                size={24}
                aria-hidden="true"
                class="shrink-0 transition-transform duration-200 ease-out group-open:rotate-180"
              />
            </summary>
            <div class="mt-md font-text text-body text-text">
              {faq.answer}
            </div>
          </details>
        ))}
      </div>

      <!-- CTA Card (D-05, D-06, D-07) — same composition family as thank-you/404 -->
      <Card elevated={true} class="max-w-2xl mx-auto text-center">
        <CardBody>
          <h2 class="font-display text-h3 font-bold text-text mb-md">Still have questions?</h2>
          <p class="font-text text-body text-text-muted mb-md">
            Tell me about your project — I usually respond within 48 hours.
          </p>
          <Button variant="primary" size="md" href="/#contact">Let's talk</Button>
        </CardBody>
      </Card>

    </div>
  </section>
```

**Per-row visual contract (D-01 RESOLVED — `p-md`):**
- Each `<details>` is a bordered row: `border border-border rounded-lg p-md bg-surface`. Padding RESOLVED to `--spacing-md` (24px) — `p-sm` (16px) reads cramped given the 24px H3 question text and the body answer copy that appears on expand.
- Vertical gap between rows: `gap-sm` (16px). Tight enough to read as a list, loose enough that each row feels self-contained.
- The `<summary>` uses `flex items-center justify-between gap-md` so the chevron sits right-aligned with `--spacing-md` separation from the question text.
- `list-none` on `<summary>` removes the native disclosure triangle (we replace it with ChevronDown per D-02).
- `cursor-pointer` on `<summary>` signals interactivity.
- `mt-md` between summary and answer body when expanded (24px breathing room).

**ChevronDown rotation contract (D-02 RESOLVED — `duration-200 ease-out`):**
- Icon: `<ChevronDown size={24} aria-hidden="true" />` — size 24px so it visually balances the 24px H3 summary text.
- `aria-hidden="true"` because the accessible name lives in the `<summary>` text per D-02.
- Closed state: chevron points down (default).
- Open state: rotated 180° via Tailwind `group-open:rotate-180` (the parent `<details>` carries `class="group"`).
- Transition: `transition-transform duration-200 ease-out` — RESOLVED to `200ms` because that exact duration is already shipped on the v2 Card hover transition (`Card.astro` line 22: `transition-transform duration-200`), keeping a single motion vocabulary across the v2 system. `ease-out` is the implicit Tailwind v4 default and is appropriate for an open-disclosure motion (decelerates as it lands).
- 150ms felt twitchy in CONTEXT discretion bracket; 300ms drags relative to user's tap. 200ms matches the system.

**JSON-LD contract (D-08):**
- `faqSchema` object pulled verbatim from current `src/pages/faq.astro` lines 35-46 (D-04: 5-question schema).
- Injected via `<script type="application/ld+json" set:html={JSON.stringify(faqSchema)} slot="head" />` so it lands in `<head>` via the BaseLayoutV2 `<slot name="head">` mechanism.
- Test contract (per D-19): `tests/accessibility/v2-leaf-pages.spec.ts` fetches `/faq`, parses the inline `<script type="application/ld+json">` content, and asserts `parsed["@type"] === "FAQPage"` AND `parsed.mainEntity.length === 5`.

- The default `ArrowRight` icon is acceptable; no need to suppress with `iconRight={null}`.
