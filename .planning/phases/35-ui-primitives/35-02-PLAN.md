Scope: static presentational Astro components + one always-dark `:root` custom property addition. No runtime JS, no forms, no user input.

| ID | Threat | Vector | Mitigation | ASVS |
|----|--------|--------|------------|------|
| T-01 | SVG injection via icon markup | The calendar/mail inline SVGs are hand-placed into CTAButton from the extraction artifact. Hostile markup could enter. | Copy only the `viewBox` + path/circle/rect geometry recorded in 35-FIGMA-EXTRACTION.md; set `aria-hidden="true"`; include no `<script>`, `on*=` handlers, `<foreignObject>`, or external `href`. | T-02 | On-dark contrast collapse | Using `var(--color-wl-on-ink)` (a flippable token) on an always-dark surface flips to ink `#12333B` in dark mode → near-zero contrast. | Ghost-on-dark and Eyebrow on-dark MUST use non-flippable literals / `:root` custom properties from 117:103 (D-10). The contrast gate (Plan 01) already has the pair; re-run it. | V14 (defense-in-depth: a11y) |

No high-severity threats — output is static markup rendered at build time.
</threat_model>
