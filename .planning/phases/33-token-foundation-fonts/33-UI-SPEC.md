## Typography Contract

### Font Loading

| Font | Package | CSS Imports | Preload in BaseLayout |
|------|---------|-------------|----------------------|
| Fraunces Variable (upright) | `@fontsource-variable/fraunces` v5.2.9 | `@import '@fontsource-variable/fraunces/wght.css'` | `fraunces-latin-wght-normal.woff2` via `?url` |
| Fraunces Variable (italic) | same package | `@import '@fontsource-variable/fraunces/wght-italic.css'` | `fraunces-latin-wght-italic.woff2` via `?url` |
| Hanken Grotesk Variable | `@fontsource-variable/hanken-grotesk` v5.2.8 | `@import '@fontsource-variable/hanken-grotesk/wght.css'` | `hanken-grotesk-latin-wght-normal.woff2` via `?url` |

**CLS = 0 strategy:** `fontaine` Vite plugin (`fontaine` v0.5.x) generates `@font-face` fallback blocks with `ascent-override`/`descent-override`/`size-adjust` metrics from the installed woff2 binary. No manual fallback metric authoring.

**Google Fonts coexistence:** The Google Fonts `<link>` block for Bricolage Grotesque + DM Sans STAYS in `BaseLayout.astro` this phase. Old utility classes (`font-body`, `font-heading`) on existing pages bind to old tokens that reference these fonts. Removal in Phase 41 only.

**`opsz` handling:** Set `font-optical-sizing: auto` on each Fraunces utility class; the browser adjusts the `opsz` axis value based on `font-size`. Only override via `font-variation-settings` for specific departures from the optical default.

**Source:** RESEARCH.md Pattern 2, Pattern 3; 33-CONTEXT.md Claude's Discretion (Fraunces preload strategy).

## Contrast / Accessibility Contract

**Standard:** WCAG 2.2 AA — 4.5:1 for normal text, 3:1 for large text (18px+ bold or 24px+ regular).

**Gate:** `scripts/check-contrast.mjs` must exit code 0 before Phase 33 is marked complete. All `FAIL` pairs in the script output must have companion `-text` tokens defined in `@theme`.

**Pair matrix (mockup-observed per D-11):** The script checks every text-on-background combination observed in Figma mockups and the Components page. Minimum required pairs:

| Foreground Token | Background Token | Context | Threshold | Expected |
|-----------------|-----------------|---------|-----------|---------- |
| `--wl-ink` | `--wl-paper` | Body text | 4.5:1 | PASS |
| `--wl-sub` | `--wl-paper` | Secondary text | 4.5:1 | PASS |
| `--wl-accent` | `--wl-paper` | Link text | 4.5:1 | Verify |
| `--wl-accent-soft` | `--wl-paper` | Body text (small) | 4.5:1 | **EXPECTED FAIL** → `--wl-accent-soft-text` companion |
| `--wl-accent-soft` | `--wl-paper` | Large text (24px+) | 3:1 | Likely PASS |
| `--wl-ink` | `--wl-sea-glass` | Text on section bg | 4.5:1 | Verify |
| `--wl-sub` | `--wl-sea-glass` | Secondary text on section | 4.5:1 | Verify |
| `--wl-accent` | `--wl-sea-glass` | Link on section bg | 4.5:1 | Verify |
| *(dark theme pairs — same combinations, dark values)* | | | | EXTRACT dark values first |

**Script implementation:** Inline W3C relative luminance formula (no npm dep). Committed to `scripts/check-contrast.mjs`. Re-runnable whenever token values change.

**Companion derivation method:** Minimally darken `--wl-accent-soft` at the same OKLCH hue until 4.5:1 on `--wl-paper` is achieved. Document the before/after hex values and ratios in the phase output for Joel's async review. No approval gate on companions — judgment happens at Phase 37/38 screenshot gates.

**Source:** 33-CONTEXT.md D-09, D-10, D-11, D-12.
