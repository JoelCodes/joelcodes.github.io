**Surface:** Removal of a client-side form that POSTed to an n8n webhook, plus removal of the `PUBLIC_N8N_WEBHOOK_URL` env reference.
**ASVS L1 review:**
- This change is a security IMPROVEMENT, not a new surface. Deleting `ContactSection.astro` removes an unauthenticated form-submission path to an external n8n webhook (the `hp-form` client script POSTing arbitrary body to `PUBLIC_N8N_WEBHOOK_URL`) — eliminating an SSRF/abuse target and a piece of client code that read an env var into the browser bundle (PUBLIC_ vars are client-exposed).

- No new input handling, no new endpoints, no new redirects are introduced by this plan.
**Conclusion:** No high/medium findings introduced. Net reduction in attack surface.
</threat_model>
