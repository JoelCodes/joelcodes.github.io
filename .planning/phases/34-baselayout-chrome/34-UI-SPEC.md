# Phase 34 — UI Design Contract: BaseLayout + Chrome

> Visual and interaction contract for the Wavelength site chrome (SiteHeader, SiteFooter, BaseLayout
> dark-mode infrastructure). Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

**Fidelity rule:** The Figma file is the single source of truth. Extracted values are shipped
verbatim, never "corrected" toward generic design heuristics. Where a generic rule (2-weight cap,
4px spacing grid) conflicts with extracted Figma values, the resolution is to DECLARE the Figma
values as explicit, justified exceptions — not to snap them to the guideline.

**Approved deviations from Figma** (locked in 34-CONTEXT.md):
- Mobile wordmark hidden (mark-only at mobile width) — D-02, user-approved due to 390px overflow
- No theme toggle in header — D-05, Figma never had one; matches Figma exactly
- No hamburger / mobile overlay — D-01, Figma mobile header is literal (mark + Showcase + CTA)

always win over the 8-point guideline.** See "Figma-native spacing exceptions" table below for
all non-4px-multiple values extracted from Figma nodes.

|-------|-------|-------|
| xs | 4px | Icon-to-text gap within a single element |
| sm | 8px | Tight internal element padding; footer left-column vertical gap (node 42:77) |
| md | 16px | Default inline padding |
| lg | 24px | General section padding (non-chrome use) |
| xl | 32px | Section-level padding unit |
| 2xl | 48px | Footer vertical block spacing |
| 3xl | 64px | Header height (exact: 64px at both 390px and 1440px — nodes 42:29, 42:47) |

### Weight exceptions — Figma-locked, not a guideline violation

The standard gsd guideline is 2 font-weights maximum per phase. The chrome uses **three weights
(400 / 500 / 600)** because the Figma components specify exactly these three:

| Weight | Where used | Figma node evidence |
|--------|-----------|---------------------|
| 400 Regular | Wordmark (Fraunces), footer tagline (Fraunces italic), footer body, footer nav links, footer bottom row | Node 42:29 wordmark, 42:77 tagline + body + nav |
| 500 Medium | Header nav links (Services / Showcase / About) | Node 42:29 nav items — explicitly "Hanken Grotesk Medium" |
| 600 SemiBold | CTA button label "Book a call" | Node 39:30 CTA label — explicitly "Hanken Grotesk SemiBold" |

This is a **Figma-locked exception** to the 2-weight guideline. The project constitution requires
extracted values to be shipped verbatim. Overriding these to 2 weights would introduce fidelity
drift and fail the screenshot gate.

## Color

### Color Contract

All chrome components use `--wl-*` tokens exclusively. No old neobrutalist tokens (`--color-yellow`,
`--color-bg-light`, etc.) may appear in SiteHeader.astro or SiteFooter.astro.

Dark mode: `.dark` class on `<html>` flips `--wl-*` token values. Chrome components use each token
once — no `dark:` prefix pairs needed for wl colors (Phase 33 D-01).

**New token required:** `--wl-on-ink` `#EAF6F3` is used for the CTA label on the ink background
and for the footer wordmark. It participates in the Figma variable system (node 42:27 `--on-ink`)
but was not included in the Phase 33 token set. It must be added to `global.css` `@theme` block
as `--wl-on-ink` with its light-mode value `#EAF6F3` and its dark-mode counterpart (verify from
Figma variable modes during implementation).

| Role | Token | Light hex | Dark hex | Usage |
|------|-------|-----------|----------|-------|
| Dominant (60%) — page surface | `--wl-paper` | `#F6FBFA` | `#0C2228` | Page background |
| Secondary (30%) — header surface | `--wl-sea-glass` | `#E6F1F1` | `#123640` | Header background (node 42:29: background is `var(--sea-glass)`) |
| Accent (10%) | `--wl-accent` | `#0E7078` | `#4FB3B8` | WaveMark strokes, nav link hover state, focus rings |
| Primary text | `--wl-ink` | `#12333B` | `#EAF6F3` | Header wordmark, nav link default, CTA button background |
| On-ink text (NEW) | `--wl-on-ink` | `#EAF6F3` | verify from Figma dark mode | CTA label text, footer wordmark text |
| Secondary text | `--wl-sub` | `#35525A` | `#A9C9C7` | Blog nav link (dev-only), muted elements |
| Divider | `--wl-line` | `#0E7078 @16%` | `#5AA9A5 @22%` | Available for dividers where Figma specifies |
| Destructive | none | — | — | No destructive actions in Phase 34 chrome |

**Accent reserved for: WaveMark strokes, nav link hover state, focus rings.**
Accent is NOT used for: CTA button background, body text, borders, wordmarks, footer elements.

**CTA button background is `var(--wl-ink)` (`#12333B` light / `#EAF6F3` dark)**, not accent.
Source: node 42:29 extraction — "background `var(--ink)`". CTA label uses `var(--wl-on-ink)`.

**Focal points:**
- Primary: "Book a call" CTA — the only filled element in the header (ink background on a sea-glass header surface).
- Footer: The Fraunces-italic tagline "On your wavelength." — the only display-weight italic element in the footer block.

### Header bottom border

Node 42:29 extraction: `1px solid var(--accent)` — full accent value, NOT the 16% `--wl-line` tint.
Use `border-bottom: 1px solid var(--color-wl-accent)`.

### Footer Color Contract (special case — always dark regardless of theme)

The footer renders on a DARK BACKGROUND in BOTH light and dark themes. It does NOT flip with the
`.dark` class. Footer colors are local values by Figma designer intent (Figma component description:
"#0D2A31 — deliberately not a token; matches mockup CSS. Muted link tints are local values.").

Implementation MAY centralize these as `--wl-footer-*` custom properties for maintainability, but
they are NOT part of the 8-token `--wl-*` palette and do NOT flip with theme.

| Element | Color | Hex | Token strategy |
|---------|-------|-----|----------------|
| Footer background | Deep ink | `#0D2A31` | Define as `--wl-footer-bg: #0D2A31` in `global.css` outside `@theme` flip blocks |
| Wordmark / brightest text | `--wl-on-ink` value | `#EAF6F3` | Reference `var(--wl-on-ink)` — this token participates in the Figma variable system |
| Tagline (Fraunces italic) | Accent-soft | `#5AA9A5` | Local value on dark bg; define `--wl-footer-tagline-color: #5AA9A5` |
| Supporting line | Muted teal | `#7FA4A2` | Local value; define `--wl-footer-text-secondary: #7FA4A2` |
| Nav links + email/GitHub row | Light teal | `#CDE6E5` | Local value; define `--wl-footer-text-link: #CDE6E5` |
| Copyright | Dim teal | `#8FB4B2` | Local value; define `--wl-footer-text-muted: #8FB4B2` |
| Divider | White at 9% | `rgba(255,255,255,0.09)` | Inline or `--wl-footer-divider` |

**Source:** 34-FIGMA-EXTRACTION.md "Footer color inventory" section — all node 42:77 extractions.
