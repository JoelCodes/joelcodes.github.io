## Color

### Color Contract

All chrome components use `--wl-*` tokens exclusively. No old neobrutalist tokens (`--color-yellow`,
`--color-bg-light`, etc.) may appear in SiteHeader.astro or SiteFooter.astro.

Dark mode: `.dark` class on `<html>` flips `--wl-*` token values. Chrome components use each token
once — no `dark:` prefix pairs needed for wl colors (Phase 33 D-01).

| Role | Token | Light hex | Dark hex | Usage |
|------|-------|-----------|----------|-------|
| Dominant (60%) — page surface | `--wl-paper` | `#F6FBFA` | `#0C2228` | Page background; header background |
| Secondary (30%) — header, card surfaces | `--wl-sea-glass` | `#E6F1F1` | `#123640` | Not used in chrome directly; available for hover states |
| Accent (10%) | `--wl-accent` | `#0E7078` | `#4FB3B8` | WaveMark strokes, CTA button background, link hover states |
| Primary text | `--wl-ink` | `#12333B` | `#EAF6F3` | Header wordmark, nav link default |
| Secondary text | `--wl-sub` | `#35525A` | `#A9C9C7` | Blog nav link (dev-only), muted elements |
| Divider | `--wl-line` | `#0E7078 @16%` | `#5AA9A5 @22%` | Header bottom border |
| Destructive | none | — | — | No destructive actions in Phase 34 chrome |

Accent reserved for: WaveMark strokes, "Book a call" CTA button background, nav link hover state color. NOT used for: body text, borders, footers, wordmarks.

### Footer Color Contract (special case — always dark regardless of theme)

The footer renders on a DARK BACKGROUND in BOTH light and dark themes. It does NOT flip with the
`.dark` class. The footer background is a standalone dark ink color not in the 8-token `--wl-*`
palette.

| Element | Color | Hex | Token strategy |
|---------|-------|-----|----------------|
| Footer background | Dark sea-glass ink | `#0D2A31` | Define as `--wl-footer-bg: #0D2A31` in `global.css` `@theme` block; do NOT scatter as raw hex literal |
| Primary text on footer | Light ink | `#EAF6F3` | Matches dark-mode `--wl-ink`; use as named constant in SiteFooter.astro OR reference `--color-wl-footer-text-primary` if defined |
| Secondary text on footer | Muted teal | `#7FA4A2` | Between `--wl-sub` dark and `--wl-accent-soft` dark; no direct token match — define `--wl-footer-text-secondary: #7FA4A2` |
| Nav links on footer | Light teal | `#CDE6E5` | Define `--wl-footer-text-link: #CDE6E5` |
| Muted / copyright | Dim teal | `#8FB4B2` | Define `--wl-footer-text-muted: #8FB4B2` |

**Source:** Phase 33 FIGMA-EXTRACTION.md "Bonus Observed Tokens" row — node `22:759` (light mockup
footer fill + text color observations). Confirmed in 34-RESEARCH.md.

**FIGMA-GAP: Footer background token status** — whether Figma has a named variable for `#0D2A31`
is unknown. If Figma `42:77` shows a named variable (e.g., `--on-ink` or a footer-specific mode),
use that name. If no variable exists, define `--wl-footer-bg: #0D2A31`. Do not use raw hex literals.

**FIGMA-GAP: Footer text color verification** — colors above are observed from mockup node `22:759`
in the light mockup. Planner must verify against Figma node `42:77` (the footer symbol) to confirm

## Interaction Contract

### Dark Mode

| Behavior | Implementation | Source |
|----------|---------------|--------|
| Theme detection | `prefers-color-scheme` only — no localStorage read | 34-CONTEXT.md D-05/D-06 |
| Theme persistence | None — OS preference is re-evaluated on every load | D-06 |
| Stale localStorage cleanup | `if ('theme' in localStorage) { delete localStorage.theme; }` in FOUC script | D-06 |
| Script placement | `<script is:inline>` in `<head>` BEFORE `<body>` — never defer, never module | 34-RESEARCH.md Pitfall 1 |
| Class applied | `.dark` on `<html>` element | Phase 33 D-01 |
| Live OS change listener | NOT required — load-time evaluation sufficient | D-06 |
| Transition flash prevention | No unconditional `body { transition: background-color }` | 34-RESEARCH.md Pitfall 6 |
