<threat_model>
Static chrome, no user input, no secrets. Narrow realistic threats (per <security_requirement>):
- **External link rel attributes:** the footer GitHub link opens a new tab; without
  `rel="noopener noreferrer"` a `target="_blank"` link exposes `window.opener` (reverse-tabnabbing).
  Mitigation: GitHub link uses `target="_blank" rel="noopener noreferrer"` (existing Footer.astro
  pattern). ASVS L1 V13.2-adjacent hygiene for external navigation.
- **mailto exposure:** `contact@joelshinness.com` is rendered in cleartext. This is an ACCEPTED
  business decision (D-07/D-08 — the site-wide public contact address). Not a vulnerability to fix.
- **No injection surface:** all copy is static verbatim Figma copy; no interpolation of untrusted data.
`currentYear` is a build-time constant, not user input.
</threat_model>
