<threat_model>
Static-site layout, no user input, no secrets. Narrow realistic threats (per <security_requirement>):
- **FOUC script integrity (availability/UX correctness, not security):** the inline script must not be
  moved out of <head> or given `defer`/`type=module` — doing so reintroduces the dark flash. Not an
  attacker threat but a documented Pitfall-1 correctness gate; verified by grep for script position.
- **localStorage handling:** the script deletes `localStorage.theme` — a same-origin operation on a
  non-sensitive key. No secret is stored there; no XSS sink is introduced (the script contains no
  interpolated/untrusted values, only static literals). ASVS L1: no injectable content.
No auth/session/crypto surface in a static layout.
</threat_model>
