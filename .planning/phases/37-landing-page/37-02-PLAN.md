<threat_model>
ASVS L1 relevant control: reverse tabnabbing (V-Communication). All Calendly CTAs open in a new tab (`target="_blank"`, D-06); without `rel="noopener"` the opened Calendly page could access `window.opener` and redirect the origin tab. Mitigation: every `target="_blank"` link in this plan MUST carry `rel="noopener"` — enforced on the header CTA, footer CTA, and the CTAButton pass-through. No forms, no user input, no secrets in this plan (the Calendly URL and contact email are public values, correctly living in source, not env). The scroll-spy script is a self-contained IIFE reading only same-origin DOM (`getElementById`), setting only an ARIA attribute — no injection surface, no external data. High-severity check: confirm no `rel="noopener"` is dropped on any new-tab link.
</threat_model>
