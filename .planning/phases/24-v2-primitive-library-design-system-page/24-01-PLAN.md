<threat_model>
ASVS L1 surface for Button.astro: minimal — Button is a presentational primitive, no user input persisted, no auth code, no secrets, no network calls. Threats considered and accepted as low/none:

- V5 Validation/Sanitization: Button renders a {...rest} spread of native HTML attributes. Astro escapes attribute values by default; href values pass through Astro's URL handling. No raw HTML injection vector unless a caller deliberately passes a malicious set:html slot — out of scope for a presentational primitive.
- V14 Configuration: No env vars, no runtime config consumed.
- V11 Business Logic: No business rules in Button.
- V13 Web Services / V9 Communications: No fetch, no API calls from Button.

Block on: high severity findings. None identified for this plan. Note for the executor: if {...rest} is spread directly onto an <a> Tag, ensure target="_blank" rel attributes are not silently dropped — pass-through is fine but document that callers are responsible for rel="noopener noreferrer" on external links (not enforced inside Button; consistent with v1 behavior).
</threat_model>

  <action>
    Create new file src/components/v2/ui/Button.astro. Frontmatter imports: `import { ArrowRight } from '@lucide/astro'` and `import type { AstroComponent } from '@lucide/astro'`.

    Props interface (export inline `interface Props`):
    - variant?: 'primary' | 'ghost' | 'link' (default 'primary' per D-01)
    - size?: 'sm' | 'md' | 'lg' (default 'md' per D-02)
    - href?: string (when set, renders <a>; otherwise <button> — D-03)
    - iconLeft?: AstroComponent (D-04)
    - iconRight?: AstroComponent | null (D-04 — null suppresses link-variant default)
    - disabled?: boolean (default false)
    - type?: 'button' | 'submit' | 'reset' (default 'button'; only applied when !href)
    - class?: string (passthrough — class:list final entry)

    Destructure with capitalized aliases for icons: `const { iconLeft: IconLeft, iconRight: IconRightProp, ... } = Astro.props`. Spread remaining native attrs as `...rest`.

    Polymorphic tag: `const Tag = href ? 'a' : 'button'`.

    Link-variant default arrow logic: `const IconRight = variant === 'link' ? (IconRightProp === null ? null : (IconRightProp ?? ArrowRight)) : IconRightProp`. This makes `iconRight={null}` explicitly suppress the default on the link variant while undefined keeps the ArrowRight default.

    Variant classes (Tailwind v4 utilities only — no scoped styles for these):
    - primary: `bg-accent text-text hover:opacity-90 transition-opacity`
    - ghost: `bg-transparent text-text border border-border hover:bg-surface-muted transition-colors`
    - link: `bg-transparent text-text hover:text-accent transition-colors link-variant` (the `link-variant` marker class is consumed by the scoped arrow-nudge style — see below)

    Size classes (per UI-SPEC table — vertical/horizontal padding):
    - sm: `px-sm py-3 text-small` (16px/12px; py-3 = 12px literal per Spacing Exceptions)
    - md: `px-5 py-sm text-body` (20px/16px; px-5 = 20px literal — Crito-verified `[16, 20]`)
    - lg: `px-lg py-5 text-body` (32px/20px; py-5 = 20px literal)

    Shared base classes (always applied): `inline-flex items-center gap-xs font-display font-medium rounded-md` (gap-xs = 8px icon-to-label gap per UI-SPEC; font-medium = Tailwind built-in 500 per RESEARCH Pitfall 6; font-display = Plus Jakarta Sans per UI-SPEC Typography table "Button label" row).

    Disabled state: append `opacity-50 cursor-not-allowed pointer-events-none` when disabled is true.

    Template root: `<Tag class:list={[...]} href={href} type={!href ? type : undefined} disabled={!href ? disabled : undefined} aria-disabled={href && disabled ? 'true' : undefined} {...rest}>...</Tag>`.

    Icon rendering inside Tag: `{IconLeft && <IconLeft size={size === 'sm' ? 14 : 16} aria-hidden="true" class="shrink-0" />}` then `<slot />` for the label, then `{IconRight && <IconRight size={size === 'sm' ? 14 : 16} aria-hidden="true" class="shrink-0" />}`.

    Scoped <style> block (ONLY for the focus-visible rule and the link-variant arrow-nudge — no other CSS):
    ```
    a:focus-visible,
    button:focus-visible {
      outline: 2px solid var(--color-accent);
      outline-offset: 2px;
    }
    .link-variant:hover :global(svg) {
      transform: translateX(2px);
      transition: transform 150ms ease;
    }
    ```
    (Note: the :global(svg) inside scoped style is acceptable because the rule is scoped to the component root via the .link-variant marker; it is NOT an is:global block. If executor finds the :global selector inside a scoped style violates the "zero is:global" rule on closer reading, fall back to: drop the arrow-nudge effect — D-20 does not require it; UI-SPEC marks the translateX as "optional implementer choice; default = stays text color".)
