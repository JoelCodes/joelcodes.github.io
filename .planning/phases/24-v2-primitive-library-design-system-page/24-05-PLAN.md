<objective>
Close UAT Gap 1 (major): the v2 token system's `--spacing-sm/md/lg/xl/2xl` declarations in `src/styles/v2/global.css` hijack Tailwind v4's `max-w-{size}` utility generator. In v4, `max-w-{size}` prefers a `--container-{size}` token and falls back to `--spacing-{size}` when no container token exists — so `.max-w-sm` currently resolves to `var(--spacing-sm)` = 16px instead of the intended 24rem (384px). The select demo wrapper at `src/pages/design-system.astro:258` (`<div class="max-w-sm mb-lg">`) is clamped to 16px, which collapses the select's `w-full` content area and makes the selected option text invisible. The same latent defect affects `src/components/v2/layout/Footer.astro:11` (`max-w-md` → 24px instead of 448px).

Fix: declare explicit `--container-sm/md/lg/xl/2xl` tokens inside the v2 `@theme` block with Tailwind's default container widths. Tailwind v4 will then prefer the container namespace and `.max-w-sm` resolves to 24rem (384px) correctly — without disturbing the existing `--spacing-*` utilities (px-sm, py-md, gap-xs, etc.) that are deliberately bound to the t-shirt scale.

Add a Playwright regression test that asserts BOTH (a) the select demo wrapper's computed `width` is ≥ 300px AND (b) the Footer.astro `max-w-md` tagline computed `width` is ≥ 300px on the standard 1280-wide chromium viewport. Covering Footer explicitly prevents a future regression where only one of the two container tokens (--container-md alone) is reverted — without the Footer assertion, that class of single-token regression would ship silently.

Purpose: this is the highest-severity gap (major — user-visible "select doesn't show text") and the easiest to invalidate later if the token system is touched again. Locking it down with computed-style tests on real page wrappers prevents future commits from re-introducing the same namespace hijack at either site.

Output: one modified file (`src/styles/v2/global.css` — 5-token block added inside @theme), one modified test file (`tests/accessibility/v2-primitives.spec.ts` — one new test appended inside the existing describe block, with assertions for both the select wrapper AND the Footer tagline).
</objective>
