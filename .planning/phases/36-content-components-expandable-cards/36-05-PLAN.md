<shared_css_ownership>
**Coordination with 36-04 (ProjectCard) — both run in Wave 2.**

The `::details-content` open/close animation and the `.wl-toggle-indicator` rotation are
patterns SHARED between FAQItem and ProjectCard (36-PATTERNS.md "Shared Patterns"). To avoid
a write race on `global.css` between two Wave-2 plans, **this plan keeps its animation and
indicator-rotation CSS SELF-CONTAINED in FAQItem.astro's own scoped `<style>` block.** Do NOT
add these rules to `src/styles/global.css` in this plan.

Rationale: self-contained `<style>` blocks in each component eliminate the cross-plan file
conflict entirely, are the Callout/ServiceCard precedent for component-local styling, and let
36-04 and 36-05 run in parallel with zero coordination. `interpolate-size: allow-keywords` on
`:root` is the ONE rule that must be global for progressive enhancement — if it is not already
present in `global.css` from an earlier plan, this plan does NOT add it (that global root rule
is owned by 36-04/ProjectCard or a foundation plan; without it, FAQItem still functions with
instant snap per D-07, which is the accepted fallback). State this in the component header
comment so 36-04 knows the division of ownership.
</shared_css_ownership>
