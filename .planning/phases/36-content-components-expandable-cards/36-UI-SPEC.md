## Interaction Contracts

### Expand / Collapse — `<details>`/`<summary>`

**Implementation:** CSS-only animation via `::details-content` pseudo-element.

```css
/* Expand/collapse animation — add to global.css or component <style> */
details::details-content {
  height: 0;
  overflow: hidden;
  transition: height 0.3s ease, content-visibility 0.3s ease;
}

details[open]::details-content {
  height: auto; /* browser resolves from 0 */
}

@media (prefers-reduced-motion: reduce) {
  details::details-content {
    transition: none;
  }
}
```

**Note on `::details-content`:** This is the spec-correct pseudo-element for animating
`<details>` open/close (supersedes the `<details summary ~ *` selector hacks). Verify
browser support at implementation time; if support is insufficient for CI browsers,
fall back to `max-height` with a generous ceiling.

### Exclusive-open FAQ (HTML `name` attribute)

All `<FAQItem>` components on a page share the same `groupName` prop value. The browser
enforces exclusive-open natively — opening one item closes all others. No JS required.

```html
<!-- Consuming page -->
<FAQItem question="..." groupName="faq-main">...</FAQItem>
<FAQItem question="..." groupName="faq-main">...</FAQItem>
```

### Focus States — All Interactive Elements

Pattern established in Phase 34/35 and carried forward without change:

```
focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-wl-accent
```

Apply to: `<summary>` in both ProjectCard and FAQItem; any `<a>` links within expanded
card content.

**Verify at axe spec:** `<details>`/`<summary>` receives `role="group"` and
`role="button"` from the browser. Confirm axe treats `<summary>` focus correctly — no
manual `role` override needed.

### Toggle Indicator Animation

Rotate the chevron/indicator icon when `details[open]`:

```css
details .wl-toggle-indicator {
  transition: transform 0.3s ease;
}

details[open] .wl-toggle-indicator {
  transform: rotate(180deg); /* chevron-down → chevron-up */
}

@media (prefers-reduced-motion: reduce) {
  details .wl-toggle-indicator {
    transition: none;
  }
}
```

**Exact indicator SVG:** FIDELITY-GAP — extract from `36:5` Project Card and FAQ Item nodes.
Do not substitute a third-party icon.
